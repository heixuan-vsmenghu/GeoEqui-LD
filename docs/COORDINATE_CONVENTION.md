# 坐标与几何契约

本文档是 GeoEqui-LD Phase 0 的唯一坐标契约。数据读取、热图、DSNT、几何变换和指标必须使用同一套定义；若后续修改约定，应先更新测试和本文件。

## 1. 关键点顺序

仓库内部固定使用原始数据字段名：

```python
KEYPOINT_ORDER = ("PS1", "PS2", "FH1")
```

通道含义：

| 通道 | 键名 | 含义 |
|---:|---|---|
| 0 | PS1 | 耻骨联合图像右端点，AoP 顶点 |
| 1 | PS2 | 耻骨联合图像左端点 |
| 2 | FH1 | 胎头切点 |

公开论文中的 `PS_R / PS_L / FH_T` 可分别理解为 `PS1 / PS2 / FH1`，但代码和结果文件继续保留原始键名，避免在数据入口处静默改名。

## 2. 基本顺序

- 点坐标始终写作 `[x, y]`。
- 图像张量和数组始终按 `image[..., y, x]` 访问。
- 尺寸参数始终写作 `[height, width]`，代码变量使用 `size_hw`。
- x 轴向图像右侧增大，y 轴向图像下方增大。
- 像素坐标表示像素中心。

## 3. 空间尺寸

Phase 0 默认值：

```text
原始图像       512 × 512
训练输入       512 × 512
目标/预测热图  256 × 256
```

原始 CSV 坐标属于原图像素空间。读取后依次得到：

```text
points_original_px  原图像素坐标
points_input_px     训练输入像素坐标
points_heatmap_px   热图像素坐标
points_normalized   训练输入对应的 [-1,1] 坐标
```

MRE 最终统一在原图像素空间计算。若模型输出来自热图或归一化空间，必须先显式映射回原图空间。

## 4. align_corners

全项目固定：

```text
align_corners = True
```

该约定令一条长度为 `W` 的轴满足：

```text
x = 0      ↔ x_norm = -1
x = W - 1  ↔ x_norm =  1
```

因此宽度为 256 时，`x_norm=0` 对应 `x=127.5`。

### 像素转归一化

```text
x_norm = 2x / (W - 1) - 1
y_norm = 2y / (H - 1) - 1
```

### 归一化转像素

```text
x = (x_norm + 1) × (W - 1) / 2
y = (y_norm + 1) × (H - 1) / 2
```

当 `align_corners=True` 时，单位空间维度没有有效的两端点定义，代码必须显式报错。

## 5. Resize

Resize 不直接散写比例公式，而是通过共享归一化空间映射：

```text
原尺寸像素 → [-1,1] → 目标尺寸像素
```

等价地：

```text
x' = x × (W' - 1) / (W - 1)
y' = y × (H' - 1) / (H - 1)
```

图像双线性插值、点坐标变换和 DSNT 网格必须使用相同的 `align_corners=True`。

## 6. Crop

若裁剪窗口左上角为 `(x0,y0)`，裁剪后坐标为：

```text
x' = x - x0
y' = y - y0
```

裁剪后必须重新检查 `[0,W'-1] × [0,H'-1]` 边界。Phase 0 不允许静默裁剪或钳制有效标签；越界策略必须由调用方明确选择。

## 7. 相似变换

当前几何一致性基础模块只接受均匀缩放和平移，不接受非均匀缩放：

```text
p' = s p + t
s > 0
t = [tx, ty]
```

变换矩阵在归一化坐标空间定义。图像采样使用逆映射，关键点使用正向矩阵；两者由同一矩阵生成。

AoP 对平移和均匀缩放保持不变，但对非均匀缩放通常不保持不变。

## 8. 水平翻转

当前训练配置禁用水平翻转。

原因是 PS1/PS2 具有图像左右端点语义。若未来启用翻转，至少必须同时完成：

```text
x' = W - 1 - x
通道 0 与通道 1 交换
FH1 通道保持不变
```

启用前必须通过图像、点坐标、热图通道和 AoP 联合测试。不能只翻图而不交换 PS1/PS2。

## 9. 高斯热图

点必须先映射到热图像素空间，再生成高斯：

```text
H(x,y) = exp(-((x-x0)^2 + (y-y0)^2) / (2 sigma^2))
```

Phase 0 默认 `sigma=4.0`，单位是 **256×256 热图像素**。热图保持连续中心，不对标签坐标做静默取整。有效但越界的点默认报错；显式无效点可以通过 mask 生成全零通道。

## 10. DSNT

DSNT 输入为 `[B,C,H,W]` 热图 logits，先在空间维度执行 softmax，再计算期望坐标：

```text
输出形状 [B,C,2]
输出顺序 [x,y]
输出范围 [-1,1]
align_corners=True
```

DSNT 是可微操作，不能用 argmax 替代其训练链路。

原始 0--1 Gaussian 直接作为 logits 做 spatial softmax 时，65,536 个背景像素会使期望坐标接近图像中心。因此监督路径明确分成三项：原始热图 MSE、DSNT 连续坐标 SmoothL1，以及预测概率图与归一化 Gaussian 之间的 Jensen--Shannon 分布约束。分布项保证用于 DSNT 的概率图本身仍呈现可解释的局部峰值。

## 11. AoP

定义三个点：

```text
v = PS1
a = PS2 - PS1
b = FH1 - PS1
```

AoP 为：

```text
AoP = arccos(clamp((a·b) / (||a|| ||b||), -1, 1))
```

- 顶点固定为 PS1；
- 结果为无向小夹角，范围 `[0°,180°]`；
- 输出单位为度；
- 不取补角，不使用有向角；
- 任一向量长度接近 0 时必须返回无效 mask 或显式报错，不得产生未处理的 NaN。

实际公开标签中，用 `∠PS2–PS1–FH1` 重算 AoP 的最大差小于 `5×10^-8°`。

## 12. 指标坐标系

- `MRE_PS1 / MRE_PS2 / MRE_FH1 / MRE_ALL`：原始 512×512 图像像素空间的欧氏距离。
- `Delta_AoP`：预测 AoP 与标签 AoP 的绝对差，单位为度。
- 不允许在输入、热图和原图三个不同坐标系之间直接比较点距离。
