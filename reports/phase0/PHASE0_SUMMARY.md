# Phase 0 总结

日期：2026-08-28

## 1. 仓库和环境

项目采用 clean-room 新仓库实现，没有在带改动的上游 baseline 仓库上继续堆代码。当前代码在 Windows、Python 3.11.4、PyTorch 2.5.1+cu121 和 NVIDIA GTX 1650 4 GB 上验证。核心实现 commit 为 `d421cab`。

## 2. 数据集实际统计

| Split | 可用图像 | 标签状态 |
|---|---:|---|
| Train labeled | 300 | 完整 |
| Validation | 100 | 完整，官方独立目录 |
| Testing | 501 | 完整，含内部重复 |
| Unlabeled | 0 | 本地缺失 |

901 张监督图全部可解码、尺寸均为 512×512、越界点为 0。文件后缀都是 `.jpg`，实际编码包含 713 JPEG 与 188 PNG；内容均为灰度，读取器显式转成单通道。

## 3. 与预期数量的差异

旧指令写 31,121 张无标签图；当前 Kaggle v1 包结构审计与 Kaggle/Zenodo 说明指向 31,421 张无标签图。完整无标签目录在本机不存在，因此目前只能记录版本差异，不能伪造无标签统计或启动真实半监督训练。

## 4. Validation 来源

100 张 validation 来自公开数据包的独立 `Validation` 目录及配套 landmarks/AoP CSV，不是从 300 张 train 中随机拆出的。本项目固定使用该划分，不做单图随机重切。

## 5. 字段与顺序

内部顺序固定为：

```text
PS1, PS2, FH1
```

Validation/Testing 的 `AOP Tangency` 在入口映射为 FH1。论文定义与 901/901 条 `PS1.x > PS2.x` 支持解释性映射 `PS1=PS_R`、`PS2=PS_L`、`FH1=FH_T`；代码仍保留原始字段名。

## 6. 坐标契约

- 点：`[x,y]`；图像索引：`image[y,x]`；尺寸：`[H,W]`；
- 全链路 `align_corners=True`；
- 输入 512×512，热图 256×256；
- MRE 统一映射回原图像素空间计算；
- 图像 warp 使用逆采样矩阵，关键点使用正向矩阵；
- 水平翻转禁用。

## 7. AoP 定义

AoP 已由全部 901 条标签确认：

```text
AoP = ∠PS2–PS1–FH1
```

顶点为 PS1，取 `[0°,180°]` 无向夹角。逐行重算最大差小于 `5×10^-8°`。

## 13. 待确认项

- 无标签图应按 31,421 还是 31,121 的哪个数据版本解释；
- 文件名前缀是否代表患者、病例或视频序列；
- checkpoint、真实图像叠加图和逐样本预测是否允许公开；
- 数据使用协议是否已由负责人或导师完成签署。

## 14. 阻塞项

- 完整无标签池缺失，真实 EMA、伪标签和几何一致性训练不可启动；
- 无患者/视频分组字段，无法证明 split 在患者级或序列级独立；
- 数据协议与网页许可表述不完全一致，公开衍生产物前需人工确认。

## 15. 下一阶段建议

1. 补齐并全量审计无标签池，先查与监督 split/Example 的重复；
2. 获取或确认匿名 patient/case/video/frame 分组；
3. 在当前监督 checkpoint 上做独立消融：GroupNorm、分布 JS 和 coordinate 权重；
4. 再实现双视图等变损失、有效视野 mask、EMA 教师和伪标签；
5. HRNet、PS/FH 解耦、可变形卷积、ASPP/SE 分开加入，不一次堆叠后宣称有效。

Phase 0 的监督部分已通过；半监督部分因真实数据缺失而明确阻塞，没有伪装完成。
