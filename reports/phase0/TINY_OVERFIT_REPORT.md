# Tiny-overfit 结果

运行日期：2026-08-28

本实验只用固定随机种子抽取的 4 张训练图，重复优化 1,000 步，用于检查数据、坐标、梯度、热图解码和模型参数更新是否贯通。真实预测图与 checkpoint 留在 Git 忽略的本地运行目录中，公开报告只保留聚合指标。

## 结果

| 指标 | 初始 | 最终 |
|---|---:|---:|
| Total loss | 1.678322 | 0.004278 |

总损失下降 99.745%，超过预设的 90% 门槛；三类点都明显靠近真值。模型参数 L1 变化量为 7,967.535，最后一步存在非零梯度，所有梯度和报告指标均为有限值，没有 NaN 或 Inf。

## 诊断结论

**门槛通过。** 当前结果支持继续启动最小监督 baseline。它只证明基础训练链路能够在极小样本上学习，不代表模型已经具备泛化能力，也不代表半监督 GeoEqui-LD 已经完成。

最初仅使用热图 MSE 与坐标损失时，虽然损失下降，预测概率图仍可能呈现大范围边缘响应。加入预测空间概率与归一化 Gaussian 的 Jensen--Shannon 约束后，三个通道形成局部峰值，MRE 和 AoP 同时明显改善。因此正式 baseline 固定保留这一分布项，并在后续做消融。
