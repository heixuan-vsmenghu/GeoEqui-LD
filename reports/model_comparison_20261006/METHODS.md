# 实现版本与方法来源

本页解释主表身份，不是新训练方案。[结果](RESULTS.md) · [数值](metrics.json)。

## 本模型

已运行HRNet-W32、PS可变形卷积/注意力、FH多尺度SE、独立解码器及S/G/P、双置信筛选、EMA。单通道512×512输入、三张256×256热图；PS1/PS2/FH1对应PSR/PSL/FHT，AoP以PS1为顶点。模块已运行不等于各组件都获证，也不等于完整训练系统已公开。

| 项目 | 原V1 | V2修订版 |
|---|---|---|
| 主体 | HRNet、PS/FH增强与独立解码器 | 保留，不换新架构 |
| 监督 | raw高斯热图MSE | coordinate＋单位质量JS桥接 |
| G/P | 初版定义 | G角差尺度归一，P变换后概率JS；双门与EMA保留 |
| 状态 | 继承e39模型、BN与Adam | 桥接使用新Adam；之后复制完整状态并固定BN运行统计 |
| 预算 | e39后18000更新 | e39后600桥接，S/FULL各3000更新 |
| 主要输出 | 最终学生，普通DSNT | 最终学生，普通DSNT |

这是组合修订，不称原MSE定义未改或把V1→V2全部变化归因于单一环节。原失败保留于[HISTORY_V1.md](HISTORY_V1.md)。

## 五指标与评价

前三项MRE分别是每个点到医生标注的平均欧氏距离，ALL为三点等权平均，原图像素而非毫米。ΔAoP是角度绝对误差均值，单位度。统一Testing501但各模型保持原生读出，并非强制同一解码。

全部样本保留，退化角度主值计180度并另记有效数。FixMatch491/501有效、有效MAE31.063、主值34.036；当前其他主表行501/501有效。原MT初版387/501有效，主值83.110。Testing曾在历史研究中使用，不作为首次独立临床确认；后续Validation补证不覆盖Testing主表。

## 基线来源与预算

| 方法 | 本机所做与未做 | 主要读出/角色 |
|---|---|---|
| T10 | 已有本机150遍终态复用 | 原argmax/64×原图尺寸 |
| MT V2 | T10终态起步、新Adam、3000步；教师train前向自行更新BN，仅参数EMA | 固定最终EMA教师；学生另作附录 |
| FixMatch | T10终态、热图硬伪标签适配、18000步、raw峰阈值0.95 | 最终学生，原argmax |
| T3 | 本地L300替代未提供参考集合、缩减预算、微批次BN；两阶段MoCo后FT，保留早停与Validation选模 | 原格点中心argmax及重合点处理 |
| T1 | 作者双学生终态直接评价，零本轮训练；非本机全流程复现 | 等权热图融合，作者DARK读出 |
| T2 | 通用蒸馏初始化；监督7500＋伪标签/增强7500次Adam，Validation选模及状态继承；未重做比赛教师蒸馏 | 原argmax，无半像素偏移 |

来源、预热、预算和读出差异限制了因果排名。作者终态和任务适配不等于原论文全流程严格复现，不能把较差适配直接当成经典方法的能力上限。
